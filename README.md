## Benches

| Bench | What you practice |
| --- | --- |
| GitHub | Public repo, tags, releases, npm dist-tags, ref compare, live watch |
| Scrape | One public page: outline, links, a simple selector |
| DNS | A, MX, TXT, PTR across Cloudflare, Google, and Quad9 |
| Phone | Country, line type, NANP split, vanity keys |
| Steno | Shorthand briefs, a timed drill, and hidden ink |

Stamps live in the browser. Fifteen of them opens God Mode.

No accounts. No private networks. No people search.
